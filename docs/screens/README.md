# Экраны

Снято с production-сборки этого репозитория (`npm run build && npm start`).
Подключаются в корневом [`README.md`](../../README.md).

Игровые экраны получены не кликами по интерфейсу: партия доигрывается до нужной фазы
тем же редьюсером, что работает в браузере (`web/src/engine/reducer.ts`), её состояние
кладётся в `localStorage` под ключом `risklab-game`, и страница открывается уже в этой
фазе. Поэтому числа на снимках сходятся между собой и воспроизводимы — партия задана
одним seed.

| Файл | Что на экране |
|---|---|
| `home-desktop.png` | Первый экран, 1440 px: бюджет, срок и три примера того, чем это кончается |
| `home-mobile.png` | Он же на 390 px — форма, в которой приложение открывают из Telegram |
| `shop-desktop.png` | Магазин полисов, месяц 3 из 6, остаток 27 400 ₽. Шесть категорий, денег на две-три |
| `event-mobile.png` | Происшествие при действующем полисе: 8 000 ₽ ущерба, 5 000 ₽ покрыто, 3 000 ₽ на игроке |
| `results-desktop.png` | Итог партии: счёт, куда ушли деньги, профиль рисков, сертификат |
| `explore-desktop.png` | Раздел «Исследуй»: категории, квиз, мифы, словарь |
| `chat-mobile.png` | Чат про страхование. Без ключа отвечает справочник — состояние по умолчанию |

Обучающие подсказки на игровых снимках отключены (`risklab_game_tutorial_done`), иначе
оверлей закрывает экран целиком.
